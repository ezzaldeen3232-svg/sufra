# سُفرة — Flutter starter

نسخة أولية تجريبية لتطبيق يجمع المطاعم والخدمات المنزلية.

## الموجود في النسخة الأولى
- واجهة عربية من اليمين إلى اليسار.
- البحث في العناصر التجريبية.
- تصفية حسب المطاعم أو الخدمات.
- إضافة العناصر إلى السلة وحذفها وتقليل الكمية.
- حساب الإجمالي بالجنيه المصري.
- تأكيد تجريبي فقط؛ لا يوجد إرسال طلب حقيقي أو دفع إلكتروني.

## إنشاء APK عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub باسم `sufra`.
2. ارفع محتويات هذا المشروع إلى جذر المستودع، مع إظهار الملفات المخفية حتى يظهر مجلد `.github`.
3. افتح تبويب **Actions** وفعّل Actions إذا طُلب منك ذلك.
4. شغّل **Build Sufra APK** عبر زر **Run workflow**، أو ادفع commit إلى فرع `main`.
5. افتح عملية البناء الناجحة، ثم قسم **Artifacts**.
6. نزّل `sufra-release-apk` وفك ضغطه؛ ستجد `app-release.apk`.

## تشغيله محليًا على الكمبيوتر
ثبّت Flutter وAndroid SDK، ثم من مجلد المشروع نفّذ:

```bash
flutter pub get
flutter run
```

ولبناء APK محليًا:

```bash
flutter build apk --release
```

## ملاحظات
- البيانات تجريبية وموجودة داخل التطبيق؛ لا توجد قاعدة بيانات أو حسابات مستخدمين.
- لا تضع مفاتيح سرية في الكود أو المستودع.
- يمكن تغيير اسم الحزمة وأيقونة التطبيق قبل النشر النهائي.
